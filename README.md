# Flit CMS

Лёгкая многоязычная CMS на PHP без внешних зависимостей: собственный шаблонизатор, хранилище пользователей в JSON или MySQL, роли, админ-панель и встроенный редактор переводов.

*FlitCMS is a lightweight multilingual content management system written in PHP. No Composer, no framework: a built-in template engine, JSON or MySQL storage, user roles, an admin panel and a translation editor.*

## Возможности

- **Шаблонизатор** с простым синтаксисом `{{...}}`, кэшированием и сжатием HTML, CSS и JS.
- **Несколько тем.** Папка с шаблонами сайта и папка шаблонов админки задаются в конфиге (`tplDir`, `tplAdminDir`).
- **Пользователи и роли** (`admin`, `user`): регистрация, вход, профиль, пароли хранятся в bcrypt.
- **Два хранилища:** JSON-файлы (не требуют базы данных) или MySQL, переключаются одной настройкой.
- **Многоязычность** (по умолчанию ru, en, de, ka): словари в `config/lang/*.json`, язык запоминается в куке `LANG`.
- **Редактор переводов в админке:** список непереведённых фраз, автоперевод через Google Translate, сохранение сразу для всех языков.
- **Админ-панель:** панель управления, пользователи, настройки, журнал, переводы, очистка кэша.
- **Журнал событий** в `log/app.log`.

## Требования

- PHP **8.1 или новее** (используются `enum` и стрелочные функции)
- Веб-сервер: nginx + PHP-FPM или Apache
- Расширения PHP: `json`, `mbstring`, `session`; для MySQL ещё `pdo_mysql`

## Установка

1. Скопируйте файлы в папку сайта.
2. Дайте веб-серверу право записи в `data/`, `log/`, `cache/`, `config/lang/` и `config/config.inc.php`.
3. Откройте `config/config.inc.php` и проверьте основные настройки (см. ниже).
4. Откройте сайт в браузере и зарегистрируйтесь. Первый зарегистрированный пользователь должен получить роль `admin`.
5. Войдите и откройте админку: `/?page=index.htm&isAdmin`.
6. **Перед запуском на публичном сервере прочитайте [SECURITY.md](https://github.com/DimaFantasy/FlitCMS/blob/main/SECURITY.md).** Служебные папки (`data`, `log`, `config`, `includes`, `cache`, `templates`) нужно закрыть настройками веб-сервера.

## Настройки (`config/config.inc.php`)

| Параметр | Назначение |
|---|---|
| `siteName`, `version` | Название и версия, выводятся на сайте |
| `adminEmail` | Адрес администратора |
| `validLanguages` | Доступные языки через запятую, например `ru, en, de, ka` |
| `defaultLanguage` | Язык по умолчанию |
| `langCookieName` | Имя куки с выбранным языком |
| `langDir` | Папка со словарями (`config/lang`) |
| `tplDir` / `tplAdminDir` | Папки шаблонов сайта и админки |
| `tplCacheDir` | Папка кэша скомпилированных шаблонов |
| `tplCompress` | Сжимать скомпилированные шаблоны |
| `tplForceCompile` | Компилировать шаблоны при каждом запросе (удобно при разработке; на боевом сайте выключите) |
| `lifeTime` | Время жизни сессии: `0` до закрытия браузера, `-1` бессрочно, число — часы |
| `storage` | `json` или `mysql` |
| `mysql` | Данные подключения к базе (хост, имя, пользователь, пароль) |
| `json` | Папка и имя файла для хранилища пользователей |

Большинство настроек можно менять из админки в разделе «Настройки».

## Структура проекта

```
index.php              точка входа, выбор шаблона и языка
ajax.php               AJAX-обработчик (пользователи, настройки, переводы...)
config/                конфиг и словари переводов (config/lang)
includes/              ядро: пользователи, шаблонизатор, переводчик, БД, логгер
templates/<тема>/      шаблоны сайта и админки
assets/                CSS, JS, изображения
data/                  данные пользователей (JSON)
log/                   журнал
cache/                 кэш шаблонов
```

## Шаблоны

Файлы шаблонов лежат в `templates/<тема>/`, страница выбирается параметром `?page=имя.htm`.

```text
{{template includes/header.htm}}      подшаблон
{{$variable}}                         вывод переменной
{{t('Текст')}}                        перевод по ключу
{{if $user->isLoggedIn()}} ... {{else}} ... {{/if}}
{{loop $items $item}} {{$item}} {{/loop}}
{{php echo 'Hello'; }}                произвольный PHP-код
```

Полный справочник по синтаксису есть в шаблоне `templates/demo/template_syntax.htm`.

## Переводы

В шаблонах и в PHP фразы оборачиваются в `t('Ключ')`. Если для ключа нет перевода в словаре текущего языка, CMS показывает его в квадратных скобках и добавляет в список непереведённых.

Откройте в админке раздел «Переводы», выберите фразу из списка, заполните нужные языки (кнопка «Translate» подставит автоперевод) и сохраните. Фраза остаётся в списке, пока не переведена на **все** языки из `validLanguages`.

Чтобы добавить язык: допишите код в `validLanguages`, создайте файл `config/lang/<код>.json` и переведите фразы в админке.
